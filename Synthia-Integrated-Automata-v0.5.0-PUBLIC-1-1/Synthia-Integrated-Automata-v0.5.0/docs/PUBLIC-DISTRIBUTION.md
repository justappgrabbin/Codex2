# Public distribution boundary

The public release intentionally omits the six raw donor ZIP archives from
`authorities/originals/`. Their filenames and SHA-256 values remain recorded in
`authorities/SHA256SUMS.txt` for provenance.

The integrated, executable vendor trees remain because Synthia uses their
unique components in the live mesh. Removing those trees would remove working
organs, state-space knowledge, and execution behavior. The private archival
release retains both the raw ZIP authorities and the integrated vendor trees.

The public release contains no detected credential files, private keys,
service-role keys, GitHub tokens, or high-risk API-secret patterns.
