# Android launcher icon

The Synthia Computer launcher icon is Alexis's existing `synthia-icon.svg` from this repo:

`computer/donors/recovered/synthai-r21.22-self-cultivation-graph-integrated/assets/synthia-icon.svg`

A copy of that SVG and a 512px PNG raster sit in this folder. Density-specific PNGs under `app/src/main/res/mipmap-*` are generated from that same SVG. Nothing new was drawn.
